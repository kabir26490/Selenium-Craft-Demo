Core Engine

The Kinetic Core.

Standard WebDriver treats interactions as simple commands. SeleniumCraft re-architects the execution layer — every click, type, and wait runs through a transactional lifecycle.

01 — Re-Acquisition
Atomic Element Healing

When the DOM shifts mid-interaction, the engine re-acquires element context within the same event loop — eliminating StaleElementReferenceException before it reaches the stack trace.

02 — Transactional Iframes
Scope-Safe Switching

Frame transitions are wrapped as transactions. FrameHelper guarantees driver state is restored to root — even when nested exceptions interrupt the flow.

03 — Shadow DOM
Deep Component Access

Navigate complex web components via recursive shadow-root resolution. Native performance, no JavaScript injection, full composability with the rest of the engine.
