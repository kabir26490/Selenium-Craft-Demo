About SeleniumCraft

SeleniumCraft is a reliability-first automation approach designed to reduce flaky test behavior by treating interactions as transactional lifecycles.

The project demonstrates practical patterns for stale-element healing, resilient waits, and deterministic iframe/shadow-dom handling in modern Selenium suites.

Java 21 Modern runtime baseline
Selenium 4 W3C-compliant WebDriver stack
ExtentReports Actionable execution insights
